Cloud Agents: Your Remote AI Coding Assistants

Cursor 2.0 introduces Cloud Agents - remote AI assistants that work independently on complex tasks while you focus on other work. Unlike traditional AI assistants that require your active attention, Cloud Agents can run in the background and even continue working when you're away from your computer.

What Makes Cloud Agents Special

Cloud Agents operate with unprecedented autonomy and reliability:

  • Independent Execution - Works on tasks without constant supervision
  • 99.9% Reliability - Enterprise-grade uptime and instant startup
  • Multi-file Operations - Can read, create, and modify multiple files simultaneously
  • Context Awareness - Understands your entire project structure and dependencies
  • Cross-Device Access - Continue conversations on web or mobile at cursor.com/agents
Using Cloud Agents

There are two ways to use Cloud Agents:

  1. Send to Cloud from Editor - While working in Cursor, you can offload long-running tasks to the cloud
  2. Cloud Agent Handoff - Prepend `&` to any message to send it directly to a cloud agent

To send work to a cloud agent from your editor:

& Refactor the entire authentication system to use JWT tokens instead of sessions. Update all relevant files, add proper error handling, and write comprehensive tests.

The agent will start working immediately in the cloud. You'll receive notifications when it completes or encounters issues.

Multi-Agent Execution

Cursor 2.0 supports running up to 8 agents in parallel on a single prompt. This powerful feature uses git worktrees or remote machines to prevent file conflicts, with each agent operating in its own isolated copy of your codebase.

Multi-agent execution is perfect for:

  • Exploring Multiple Approaches - Try different implementations simultaneously
  • Parallel Workstreams - Work on independent features at the same time
  • A/B Testing - Compare different solutions side-by-side
  • Speed - Complete large refactors faster by parallelizing work
Practical Example

Let's see Cloud Agents in action with a realistic scenario:

& I need to add authentication to my API. Create: 1. JWT token generation and validation 2. User registration endpoint 3. Login endpoint with password hashing 4. Protected route middleware 5. Refresh token mechanism 6. Unit tests for all components Use Express.js and follow security best practices.

The cloud agent will break this down into subtasks, work on them systematically, and notify you when complete. You can check progress at any time on cursor.com/agents.

Plan Mode with Cloud Agents

You can combine Cloud Agents with Plan Mode for even better results:

  1. Agent creates a detailed plan with one model
  2. You review and approve the plan
  3. Agent executes the plan in the cloud (optionally with parallel agents)

To use Plan Mode, start your request with `/plan`:

/plan & Migrate our entire database schema from MongoDB to PostgreSQL, including data migration scripts
Best Practices
  • Use cloud agents for tasks that take more than 5 minutes
  • Provide clear, detailed instructions for complex tasks
  • Check progress regularly on cursor.com/agents
  • Use multi-agent execution when exploring different approaches
  • Combine with Plan Mode for complex refactors
Cloud agents have access to your codebase. Always review their changes before merging, especially for security-critical code.
